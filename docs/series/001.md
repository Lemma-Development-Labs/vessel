## Series 001 (terms)

This page defines the concrete coupon + accounting terms for the current testnet series:

- Hull coupon: fixed at purchase (published parameter — never “APY”).
- Loss routing: Ballast absorbs first, then reserve. If losses would exceed that, settle **reverts** (`HullImpairment`) — Hull is not haircut on-chain today.
- Subordination floor: Hull issuance is capped by Ballast via an on-chain reversion rule.
- Testnet underlying under consideration: **MON** only (not ETH/BTC/LST multi-market in present tense).

Where needed, refer back to `/product/hull`, `/product/ballast`, and `/product/waterfall` for the full regime order.
