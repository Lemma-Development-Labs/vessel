## Completed and how to use it

1. **App on the v2 book** (`app/`, `lib/book/`). Routes: `/deposit`
   (Ballast request or Hull subscription, allowance and stage capacity,
   pre-flight reasons mirroring every `requestDeposit` revert), `/portfolio`
   (positions, requests, refunds, Hull claims), `/withdraw` (Ballast exits,
   48 h cooldown, partial fills, escrow claims), `/series`, `/transparency`
   (book, cover vs 20%/30%, engine SIMULATED, caps, `/v1` independent check,
   event history, governance roles, Sourcify state for all v2 contracts).
   Mock demo states via `NEXT_PUBLIC_USE_MOCK=1` and `/demo`.
2. **Terminal** (`/terminal`): BOOK reconciliation (recomputed vs recorded A,
   unsettled result), RISK limits and mode, HEDGE/CARRY/OPPORTUNITIES with
   explicit reasons (G01) and an opportunity verdict that refuses entry,
   SERIES, TAPE. ⌘K typed command palette (read, verify, navigate, prepare).
3. **SDK** (`packages/sdk`): `Vessel.testnet()` reads with the verifier's own
   code; `prepare*` returns ordered unsigned calls with the wallet boundary
   and expiry.
4. **MCP** (`tools/vessel-mcp`): 15 read/verify tools over stdio; 8 prepare
   tools only with `VESSEL_MCP_PREPARE=1`. Docs: [../MCP.md](../MCP.md).
5. **Release record**: [../release/testnet-v2-release.json](../release/testnet-v2-release.json).

## Decisions

- The v0 provider, mock and exit flow were removed from the app; the v0 ABI
  and address files stay because `scripts/keeper.ts` and `scripts/e2e.ts`
  still use them.

  manifest) and `scripts/sync-packages.mjs` (verifier → service/SDK, SDK →
  MCP). Both have `--check`.
- Below 1024 px the primary nav is the bottom bar so the header never
  overflows; Terminal is desktop-only in the nav (reachable by URL).
